Sales Data Analysis Using Python

Project Overview

This project focuses on Sales Data Analysis using Python. It uses a sales dataset to explore and understand sales information through data analysis and visualization.

Objectives

- Analyze sales data using Python.
- Understand the dataset using Pandas.
- Perform data analysis and extract insights.
- Visualize sales data using Matplotlib.
- Present the analysis in a clear and understandable format.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Dataset

- File: "sales_dataset_300.csv"
- Contains sales data for analysis.

Project Files

- "mini_project.ipynb" – Python analysis and visualizations.
- "sales_dataset_300.csv" – Dataset used for analysis.
- "Sales_Data_Analysis_MINI PROJECT.zip" – Project ZIP file.

Conclusion

This project demonstrates the use of Python libraries for sales data analysis and visualization.
